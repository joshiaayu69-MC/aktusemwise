# Archive

Private working area.

- `raw/` is gitignored. Use it for temporary source downloads that you are allowed to store
  locally. Delete them when the fact sheet is complete.
- Do not put copyrighted scans in Git, even in a zip.
- Do not put student data here.
- Keep only what the licence allows you to keep.

The archive is not a publishing location. Published PDFs go to R2.
