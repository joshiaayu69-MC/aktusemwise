# Permissions

Store written permission here, one file per permission, named
`<publisher-slug>-<date>.md` or `.txt`.

A permission record must include:

- the publisher and the exact work,
- the scope (rehost, adapt, translate, commercial use),
- the territory and duration,
- the attribution line required,
- the date and the person who granted it,
- a copy of the email or letter.

Do not publish a `permission-granted` resource until the permission file exists and the
editor has checked the scope. If the permission is ambiguous, treat the source as `blocked`.
