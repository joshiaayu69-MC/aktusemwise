# Reference

Allowed reference texts for fact checking: official syllabus PDFs, open-licensed books, and
permission letters.

Do not commit publisher textbooks, coaching PDFs, pirated scans, or any file whose licence
does not allow local storage. Link those sources instead and record the link in
`sources.yaml`.

Large reference files belong in private storage, not in Git. If a file must be local for
review, place it in `content-ops/archive/raw/`; that folder is gitignored.
